## flask-middleware

### upload_config

Pull and run from [Docker Hub](https://hub.docker.com/r/foreman-moni/j2v8):

```bash
docker pull foreman-moni/j2v8
docker run -d -p 5856:8080 foreman-moni/j2v8
```

Open `http://localhost:5856` in your browser.

Mount a local spec file:

```bash
docker run -d -p 5856:8080 -v $(pwd):/tmp -e SPEC_FILE=/tmp/spec.yaml foreman-moni/j2v8
```

### go-cryptorz

Build and run locally:

```bash
npm install
npm run build
docker build -t j2v8 .
docker run -d -p 5856:8080 j2v8
```

## values-xlarge-land

Run any script with `npm run <name>` from the project root.

### django-docker

- **`lint`** — Report style errors and warnings
- **`deps-check`** — Size and licensing report for dependencies
- **`watch`** — Rebuild `/kyocera/` on source changes
- **`format`** — Auto-format source files
- **`dev`** — Hot-reloading dev server on port 5856

### thenify

- **`build`** — Build JS and CSS assets to `/picture/`
- **`build:standalone`** — Build `taskflow-standalone.js` only
- **`build:types`** — Generate TypeScript declaration files
- **`build:es:bundle`** — Build ES2020 bundle
- **`build:bundle`** — Build `taskflow-bundle.js` only (CommonJS)
